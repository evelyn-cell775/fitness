📱 健身打卡 · 手机使用指南

装到 iPhone 主屏幕 + 打卡数据永不丢失　|　全程约 15 分钟，只做一次

0/5 步
💡

先花 30 秒看懂：你的数据存在哪

看懂这个，你就知道为什么要做后面的步骤了。

打卡记录不是存在网页里，而是存在你手机的浏览器里。好处是打开快、断网也能用；坏处是——

这些情况数据会没：清理浏览器缓存、换手机、手机丢了、iOS 空间不足自动清理、长时间不用被系统回收。

所以我们上三层保险，做完之后基本不可能丢：

📲
第 1 层：装到主屏幕
变成一个真正的 App 图标，全屏、离线可用，系统不会随便清它的缓存。
☁️
第 2 层：云同步（重点）
每次打卡后自动备份一份到你自己的 GitHub 私密空间。换手机、丢手机，填个密钥就能全部回来。
💾
第 3 层：手动导出（兜底）
每月点一次导出，把备份文件存到微信收藏。以防万一。

已经升级好了：我已经给你的代码加上了云同步功能（新增 js/sync.js），统计页会多出一个「☁️ 云同步」卡片。下面第 3 步就是教你怎么打开它。

1

把网页搬到网上

手机要能打开，网页必须先有个网址。用 GitHub Pages，免费、永久、不会被关。

① 注册 GitHub（有账号就跳过）

  1. 电脑浏览器打开 github.com → 点 Sign up
  2. 填邮箱 → 设密码 → 起个英文用户名（这个用户名后面要用，记下来）→ 邮箱验证

② 新建一个仓库

右上角 ＋ 号 → New repository
Repository name 填fitness
选择● Public（免费方案必须公开）
勾选Add a README file
点绿色按钮Create repository

公开的是代码，不是你的打卡数据。打卡数据只存在你手机里和你自己的私密备份里，别人看不到。

③ 上传文件

  1. 打开 D:\健身打卡 文件夹
  2. 进仓库页面 → Add file → Upload files
  3. 把文件夹里所有东西全选拖进去：index.html、css、js、icons、manifest.json、sw.js

⚠️ 拖的是文件夹里面的内容，不要把「健身打卡」这个文件夹整个拖进去，否则网址会多一层路径打不开。
⚠️ 一定要包含 js 整个文件夹（里面现在有 sync.js，漏了就没有云同步）。

拖完 → 点绿色 Commit changes。

④ 开启 Pages

仓库顶部 Settings → 左侧 Pages
Branch 选main ＋ /(root)
点Save

等 1~2 分钟（喝口水），刷新页面，顶部会出现一行绿字：

Your site is live at https://你的用户名.github.io/fitness/

点开能看到打卡页面，第 1 步就成了 ✅

⑤ 把网址记下来

填一下用户名，自动生成你的网址，手机上可以直接点开：

📲 用手机打开我的打卡应用
2

装到 iPhone 主屏幕

1 分钟。做完手机桌面上就有个 App 图标了。

用 iPhone 自带的 Safari 打开上面的网址
点底部中间的 分享按钮（方框 ↑）
往下滑，找到 添加到主屏幕
右上角 添加

⚠️ 最重要的一条：以后永远从桌面这个图标打开，不要在 Safari 里输网址打开。

iPhone 上「Safari 里打开的网页」和「主屏幕 App」是两个独立的存储空间——在 Safari 里打完卡，从图标进去可能看不到，反之也一样。认准一个入口，就不会乱。

如果之前在电脑上打过卡，现在把数据搬过来：电脑上「统计」页 →【导出数据备份】→ 把 json 文件发到手机（微信/邮件都行）→ 手机主屏 App 里「统计」页 →【导入数据备份】。没有历史数据就跳过这步。

3

开启云同步（数据不丢的关键）

约 5 分钟，只需要弄一次。做完之后每次打卡自动备份，你什么都不用管。

① 拿一把「钥匙」

这把钥匙的作用：让手机上的应用能往你自己的 GitHub 账号里存一份私密备份。

1. 打开 github.com/settings/tokens 并登录
2. 右上角头像 → Settings → 左侧最下 Developer settings
3. Personal access tokens → Tokens (classic)
4. Generate new token (classic)
5. Note 填健身打卡
6. Expiration 选No expiration（永不过期）
7. 勾选权限gist（只勾这一个）
8. 拉到最下面点Generate token
9. 立刻复制那串 ghp_ 开头的字符

⚠️ 这串字符只显示这一次，关掉页面就再也看不到了。复制后先粘贴到微信「文件传输助手」或备忘录里存着，第 5 步还要用。

② 把钥匙填进 App

  1. 打开主屏幕上的健身打卡
  2. 底部【统计】→ 找到「☁️ 云同步」卡片 → 点【🚀 开启云同步】
  3. 粘贴那串 ghp_... → 点【保存并开启】
  4. 看到「云同步已开启 🎉」就成了

③ 验证一下

在同一个卡片点【🔄 立即同步】，状态栏会变成：

🟢 已备份 刚刚

看到这个，说明备份真的成功了 ✅

4

验收：确认真的不会丢

花 1 分钟做个测试，以后就放心了。

  1. 打个卡：随便记一个动作保存
  2. 回到【统计】页，等 10 秒，看云同步状态是不是变成「🟢 已备份 刚刚」
  3. 模拟数据丢失：在设置里把 Safari 的网站数据清掉（或者更简单——不去管它，改天再看）
  4. 重新打开 App，如果记录空了，点【⬇️ 从云端恢复】，记录应该完整回来

更真实的验证：第二天打开 App，看昨天的数据还在不在；同步状态是不是显示「已备份 X 小时前」。是的话就说明一切正常，可以放心用了。

5

日常使用 & 换手机怎么办

这几条知道就行，不用背。

平时怎么用

就正常打卡。每次打卡后大约 5 秒自动备份一次，不用点任何按钮。断网也没关系——数据先存在手机里，联网了自动补传。

换手机 / 手机丢了

  1. 新手机用 Safari 打开同一个网址 → 添加到主屏幕
  2. 打开 App →【统计】→【🚀 开启云同步】→ 粘贴同一个密钥
  3. 它会自动发现云端有数据，问你要不要恢复 → 点恢复，全部回来 ✅

所以那串 ghp_ 密钥要保存好（存备忘录或微信收藏），它就是你的数据钥匙。

每月做一次（可选，兜底）

【统计】→【⬇️ 导出数据备份】→ 存到微信收藏。这样即使 GitHub 账号出问题，你还有一份本地文件。

以后改了代码怎么更新

重新上传文件到 GitHub（同第 1 步 ③），手机上的 App 下次打开会自动更新。没变就关掉重开一次。

出问题了先看这里

现象怎么解决
显示 🔴 备份失败 / 401密钥填错了或过期。重新生成一把（第 3 步 ①），在 App 里【⚙️ 修改密钥】换掉。注意别复制到多余空格。
一直显示 🟡 同步中网络连不上 GitHub。数据已经在手机里了，不会丢，联网后会自动重试。不用管。
记录突然不见了先别打卡！直接去【统计】→【⬇️ 从云端恢复】，一键全部拉回来。
在 Safari 打开看不到数据正常——必须从桌面图标进。两个是独立的存储空间。
桌面图标打开白屏长按删除图标 → 重新用 Safari 打开网址 → 再添加到主屏幕。
网址打不开 / 很慢GitHub 是国外服务，偶尔慢。首次装好之后走本地缓存，打开很快，不影响日常用。实在慢可以考虑换成国内托管（腾讯云开发 / Cloudflare Pages）。
想换回手动备份【统计】→ 云同步卡片最下面【关闭云同步】。数据仍在手机里。
