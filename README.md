# 健身打卡（自用 PWA）

一个零依赖的个人健身打卡网页应用：**每日打卡 + 动作库 + 资料**。打卡时直接从动作库选择动作卡片，可选填写组数/次数/重量/备注；支持**一键复制历史打卡计划**（打卡弹层点「📋 复制历史计划」，或日历任意过去日期点「复制到今日」）；「资料」板块用来存放网上收集的相关内容（标题/分类/原文链接/笔记）。

## 电脑上使用

双击打开 `index.html` 即可使用，无需安装任何东西。数据保存在浏览器中。

## 手机上使用（像 App 一样）

详见 **`手机部署傻瓜教程.md`**：三种方式任选（GitHub Pages 推荐 / Cloudflare Pages / 同 WiFi 局域网），附「添加到主屏幕」步骤与数据迁移说明。局域网方式可双击 `手机访问-局域网.bat` 一键启动。

## 主题颜色

「统计」页可随时切换主题颜色（活力绿/梦幻紫/清新蓝/活力橙/樱花粉/深夜黑），选择会记住，下次打开不变。

## 数据说明（重要）

- 所有数据保存在**本机浏览器的 localStorage** 中，不上传任何服务器。
- 换浏览器 / 换设备 / 清理浏览器数据前，请先在「统计」页【导出数据备份】，再到新设备【导入数据备份】恢复。
- iOS Safari 对未安装到主屏幕的网页，长时间不访问可能自动清理数据；添加到主屏幕后数据会长期保留。

## 文件结构

```
健身打卡/
├── index.html          # 应用入口
├── css/style.css       # 样式（移动优先，绿色主题）
├── js/store.js         # 数据层：localStorage 读写（动作/打卡/资料/主题）、统计、导入导出
├── js/seed.js          # 首次使用时预置的动作库（健身 + 康复，25 个动作）
├── js/ui.js            # 界面渲染、弹层、打卡流程、资料、主题
├── js/app.js           # 入口、Tab 切换、全局交互
├── manifest.json       # PWA 配置
├── sw.js               # Service Worker（离线缓存）
└── icons/              # 应用图标
```
